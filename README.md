# VELOCITY — Beyond the Drive

A cinematic, dark supercar concept website built with **HTML, CSS and vanilla JavaScript**.

## Features
- Full-screen cinematic hero section
- Dark luxury visual style with red accents
- Scroll reveal animations
- Subtle parallax movement
- 3D tilt interaction on car cards
- Animated statistics counters
- Responsive mobile navigation
- Reduced-motion accessibility support

## Run locally
No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code **Live Server** extension.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `velocity-supercar`).
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site.

## Customize
- Change the car photos in `style.css` (search for `images.unsplash.com`).
- Edit model names and specifications in `index.html`.
- Adjust colors in the `:root` section at the top of `style.css`.

## Note
VELOCITY is a fictional concept brand. Vehicle names and performance figures are illustrative, not real manufacturer specifications. Photos load from Unsplash and therefore require an internet connection.
